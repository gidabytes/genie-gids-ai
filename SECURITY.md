# Security policy

This repository holds the public website for **Genie — GIDS AI Assistant**: three static pages, their stylesheet and images, a check script and a GitHub Actions workflow. The Genie desktop application itself is not in this repository.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Use GitHub's private vulnerability reporting for this repository: open the **Security** tab and choose **Report a vulnerability**.

If that option is not shown, private reporting has not been enabled yet. In that case, open a public issue that only says you have a security report and need a private channel, with no details.

Useful information for a private report:

- what is affected (a page, the publishing workflow, or behavior described in the Privacy Statement);
- the steps to reproduce it, and what you expected instead;
- a proof of concept, limited to what is needed to show the problem.

Never include passwords, tokens, personal data or other secrets in a report.

## What to expect

This is a personal, non-commercial project maintained by one person. There is no guaranteed response time. Fixes are published in this repository.

## Scope

- In scope: this website's pages and assets, the publishing workflow, and inaccuracies in the Privacy Statement that affect people's privacy.
- Out of scope: GitHub's own infrastructure (report to GitHub) and third-party services named on the site (report to those providers).
