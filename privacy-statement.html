Privacy Statement

Draft, pending the owner's review. This statement was written from a review of Genie's source code and settings on 24 October 2026. It has not been reviewed by a lawyer.

Points marked Owner review still need the owner's decision.

In short

  • This website uses no cookies, analytics, ads, forms or scripts. GitHub, which hosts it, logs visitors' IP addresses for security.
  • Genie runs on its owner's own computer. Its AI models run there too, and its AI service is set to refuse cloud AI providers.
  • A few optional features use online services: Microsoft 365 (read-only email), cloud voices and Wikipedia searches. Section 5 lists exactly what each one sends.
  • Genie's code contains no telemetry, analytics or crash reporting.
  • What Genie keeps stays on the computer, with the retention periods in section 7, and can be deleted at any time.

1. What this statement covers

Genie — GIDS AI Assistant (“Genie”) is a personal, non-commercial AI assistant project run by an individual owner (“the owner”). This statement covers:

  • this website, which describes the project and publishes its policies; and
  • the Genie desktop app, which runs on Linux computers the owner controls, together with its Microsoft Entra app registration: the sign-in record that lets Genie read a Microsoft 365 mailbox with permission.

“You” means anyone who uses Genie or signs in to its Microsoft app registration. Genie is not sold and is not offered as an online service.

2. This website

  • The pages are static files hosted by GitHub Pages.
  • The site uses no cookies, browser storage, analytics, advertising, tracking pixels, forms, embedded content, JavaScript, or third-party fonts and scripts.
  • GitHub logs the IP address of every visitor for security purposes, whether or not the visitor is signed in to GitHub, as described in GitHub's documentation for GitHub Pages. GitHub handles that information under the GitHub General Privacy Statement.
  • The owner has not added any analytics or visitor tracking to this site.

3. Information Genie processes

Depending on the features in use, Genie processes:

  • what you type or say to it;
  • files, folders, selected text or clipboard text that you choose to give it;
  • text read from your screen, when you ask;
  • information about the computer, such as storage, memory, processor load, battery and network status, to answer questions and run diagnostics;
  • if you sign in to Microsoft 365: your name and email address, and for the messages Genie looks at, the sender, To and Cc recipients, subject, time received, importance, a short preview and whether the message has attachments. The full message text is fetched only when Genie reads a particular message. Attachments are never downloaded; and
  • your settings and permission choices.

Genie's camera permission is set to deny.

4. Where processing happens

  • Language models run on the computer, served by llama.cpp and Ollama, and accept connections only from the computer itself.
  • Cloud AI providers are switched off. Genie's AI service is configured to refuse remote AI providers. If one were enabled later, text you attach, such as selected or on-screen text, would still need your approval each time before it was sent.
  • Email stays with local models. Genie refuses to work with email if its AI provider is not on the computer.
  • Speech is processed on the computer. Speech recognition (Whisper) and the default voice (Piper) run locally. Audio is kept in memory, never written to disk, and discarded after use, unless you explicitly save a recording.
  • Hands-free mode keeps the microphone open while it is on, with a visible indicator. Speech that is not addressed to Genie with its wake phrase is discarded.
  • Screen reading uses on-device text recognition (Tesseract). The screenshot is a private temporary file that is deleted immediately, and secrets found in the recognized text are hidden.
  • Tone. Genie may adjust the tone of a reply based on the wording of your request. That guess is never stored, logged or sent.

These are the only features in Genie's code that contact services outside the computer. (A website you ask Genie to open is opened by your web browser.)

About the Gemini voice. When a free (unpaid) Gemini API key is used, Google's terms allow Google to use submitted content to improve its products and allow human reviewers to read it, and they ask users not to submit sensitive, confidential or personal information. Keep this in mind before choosing the Gemini voice: anything Genie says aloud, including email summaries, would be sent to Google.

6. Microsoft 365 sign-in and email

  • Sign-in happens on Microsoft's own page in your web browser. Genie never sees your password.
  • How Genie signs in. As a desktop app, using the OAuth 2.0 authorization code flow with PKCE and a temporary return address on the same computer. It has no client secret.
  • Permissions. Genie requests only these delegated permissions: User.Read (your basic profile), Mail.Read (read your mail), offline_access (stay signed in), and openid and profile (sign-in). It does not request permission to send, change or delete mail.
  • Tokens. The long-lived sign-in (refresh) token is stored in your desktop keyring. Short-lived access tokens are kept in memory only.
  • How much Genie reads. At most 25 messages per request. Message text is fetched as plain text and limited to 20,000 characters per message.
  • Processing. Email text is processed only by AI models on the computer, and it is treated as untrusted information, never as instructions.
  • Kept on the computer: the IDs of up to 300 recently seen messages (no content), the order of your last inbox list (IDs only), and any reply drafts you ask for, saved as private files marked as local drafts that were not sent.
  • Alerts. When the background check is on, Genie looks for new mail every 15 minutes. If a message seems to need you, Genie shows a desktop notification with the sender's name and a one-line summary and may read it aloud. The background job also writes that line to the computer's system log (journal), which keeps it according to the computer's log settings.
  • Sending is not available. Reply drafts are never sent.
  • Stopping access. Run genie email signout to delete the stored token, and remove the app's access at My Apps or through your organization's administrator. Microsoft keeps its own sign-in records under its policies and your organization's settings.

7. What is stored, where, and for how long

Everything below stays on the computer. ~ means the user's home folder.

Data Genie keeps on the computer
DataWhereHow long
Conversation history ~/.local/share/golden-gate/history.db Deleted automatically after 30 days. History can be switched off, and gg-ai history purge --yes deletes all of it.
Activity (audit) log ~/.local/share/genie/audit.jsonl Records actions, permissions and outcomes, with only the length of each request, not its text. A new file starts at 5 MB and one previous file is kept. genie audit clear deletes both.
Memory notes ~/.local/share/genie/memory.db Off by default. Only notes you explicitly ask Genie to keep, until you delete them. genie memory clear --yes deletes all notes; genie memory erase --yes also deletes the file and turns memory off.
Search index ~/.local/share/genie/index.db Covers only folders you add. genie index remove drops a folder; genie index delete deletes the index.
Tasks and pending actions ~/.local/share/genie/tasks.db and actions.db Kept until removed. genie data purge tasks (or actions) deletes finished items older than 30 days by default.
Email state and drafts ~/.local/share/genie/ (email files and email-drafts/) Message IDs only, up to 300. Drafts stay until you delete them with genie email drafts --clear.
Sign-in tokens and API keys Desktop keyring (Secret Service) Until you sign out or remove the key.
Settings ~/.config/genie/ and ~/.config/golden-gate/ Until you change them.
Audio Memory only Not stored, unless you explicitly save a recording.
Screenshots for screen reading Private temporary file Deleted immediately after reading.
Background service messages The computer's system log (journal) Status and counts only, such as the length of a request, except the email alert line described in section 6. Kept under the computer's log settings.

Genie creates its private files, including the conversation history, activity log, memory and email drafts, so that only your user account can read them.

8. Telemetry, logs and error reporting

  • Genie's code contains no telemetry, analytics or crash reporting. This was checked on 24 October 2026 by searching the code and listing every network address it can contact.
  • Genie turns off the Hugging Face library's telemetry in its speech tools.
  • Genie does not send usage data to the owner or to anyone else.
  • Local logs are listed in section 7. Nothing in them is uploaded.
  • Software that Genie relies on, such as Ollama, llama.cpp and the operating system, is separate software with its own behavior and settings.

9. Sharing

  • The owner does not sell, rent or trade personal information, and Genie shows no advertising.
  • Information reaches other companies only through the optional features in section 5, when you use them.
  • What you do with Genie's output, such as copying a draft into an email, is up to you.

10. Security measures and their limits

Measures in place:

  • Separate allow, ask or deny settings for each kind of access. Administrator-level changes are never automatic.
  • Sign-in tokens and API keys are kept in the desktop keyring and sent only in request headers to the service they belong to.
  • Local AI servers accept connections only from the same computer. The Microsoft 365, cloud voice and web search features can each reach only their own fixed list of hosts, over HTTPS.
  • Text from email, web pages and the screen is treated as untrusted data. Secrets detected in screen text are hidden, and searches or memory notes that look like secrets are refused.
  • Private files are created with owner-only permissions.

Limits:

  • Genie does not separately encrypt its files. They are protected by your user account and by any disk encryption on the computer, so anyone who can use your account can read them.
  • AI output can be wrong. Review it before relying on it.
  • No software or online service can be guaranteed completely secure.

11. Your choices

  • Review or change permissions: genie permissions.
  • Conversation history: gg-ai history purge --yes deletes it, or switch history off in Genie's AI service settings.
  • Activity log: genie audit clear deletes it and genie audit disable turns it off.
  • Memory: genie memory off, genie memory clear --yes or genie memory erase --yes.
  • Email: genie email watch off stops background checks, genie email signout signs out, and genie email drafts --clear deletes drafts.
  • Voice: genie voice provider local switches back to the on-device voice, and genie voice key <provider> --clear removes a stored cloud key.
